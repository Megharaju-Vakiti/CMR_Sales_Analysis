# CRM Sales Analysis

A CRM sales performance analysis project focused on evaluating sales opportunities, deal outcomes, quarterly performance, and individual sales-agent performance.

## 📊 Project Overview

This project analyzes CRM sales data to understand opportunity outcomes and identify patterns in sales performance across different quarters and sales agents.

The analysis focuses on **Won vs. Lost opportunities**, quarterly trends, win rates, and sales-agent performance.

## 🔍 Key Analysis

* Total sales opportunities
* Won vs. Lost opportunities
* Overall win rate
* Quarterly opportunity performance
* Quarterly Won/Lost rate
* Sales-agent performance
* Sales-agent opportunity counts
* Comparison of sales agents across quarters
* Identification of high-performing sales agents

## 📈 Key Findings

* Total opportunities analyzed: **1,985**
* Overall Won rate: **60.3%**
* Overall Lost rate: **39.7%**
* The analysis compares performance across **2017 Q1–Q4**.
* Sales-agent performance is evaluated based on opportunity counts and quarterly activity.

## 🛠️ Tools Used

* **Excel / Google Sheets** – Data preparation, pivot tables, and analysis
* **Data Visualization** – Charts and KPI reporting

## 🎯 Objective

The objective of this project is to analyze CRM sales data and provide clear insights into sales opportunity outcomes and sales-agent performance, helping identify trends and areas for improving sales effectiveness.
